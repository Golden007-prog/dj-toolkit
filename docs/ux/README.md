# UX documentation

Why the app looks and talks the way it does. Start here.

| File | Read it when you… |
|---|---|
| [PERSONA.md](PERSONA.md) | write or change any user-facing text; who "Rio" is and what they see every day |
| [VOICE.md](VOICE.md) | need the voice, the glossary, copy patterns and the checklist for a string |
| [DECISIONS.md](DECISIONS.md) | want the owner's feedback, what we tried, what is still open (**append to it**) |
| [SKILLS.md](SKILLS.md) | want the optional third-party design and writing skills, or the rules for installing any |

Rules of thumb: write for Rio; say what will happen before it does; one name per thing; never surprise the user;
remember what they chose; tell the next person what you decided and why.
